## 3. Key Feature Specifications & Conversions

### A. Google Maps Integration (Replacing Leaflet)

1. Load Google Maps using `LoadScript` or `useJsApiLoader` with Map ID support for dark/satellite styling.
2. Render map type as **Satellite / Hybrid** by default (`mapTypeId: 'hybrid'`).
3. Replace Leaflet overlays with native React Google Maps components:
* **Field Boundary:** `<Polygon>` with editable / custom styling.
* **Lawnmower Path:** `<Polyline>` (Dashed lines for planned, solid green for sprayed pass).
* **Drone Position:** Custom Overlay (`<OverlayView>`) or SVG Marker with rotation support based on `telemetry.heading`.


4. **Drawing Tool Controls:** Map overlay action bar for:
* `[DRAW FIELD BOUNDARY]`, `[FINISH BOUNDARY]`, `[UNDO POINT]`, `[CLEAR FIELD]`, `[RECENTER DRONE]`.
* Enable point-and-click vertex placement on the Google Map when drawing mode is active.



### B. Bidirectional ROS2 / Raspberry Pi 5 Wi-Fi Connection

Integrate `roslibjs` to connect to `ws://<pi_ip>:9090` (defaulting to `ws://192.168.1.100:9090` with configurable IP in settings):

1. **Subscribed ROS Topics (Telemetry Input):**
* `/drone/gps/fix` (`sensor_msgs/NavSatFix`): Latitude, Longitude, Altitude, Satellite Count, HDOP.
* `/drone/battery` (`sensor_msgs/BatteryState`): Voltage, percentage, estimated remaining time.
* `/drone/imu` (`sensor_msgs/Imu`): Orientation (Roll, Pitch, Yaw / Heading).
* `/drone/spray/telemetry` (Custom / JSON): Tank level (L), flow rate (L/min), nozzle pressure (bar).
* `/drone/environment` (`sensor_msgs/FluidPressure` / Custom): Ambient temp, humidity, wind speed, wind direction.


2. **Published ROS Topics (Commands & Coordinates Output):**
* `/mission/field_boundary` (`geometry_msgs/PolygonStamped`): Sends finalized boundary coordinates ($lat, lng$ array) upon closing perimeter.
* `/mission/parameters` (`std_msgs/String` / JSON): Swath width, headland margin, target dosage (L/ha), flight speed, nozzle mode.
* `/drone/cmd_vel` or `/gimbal/cmd` (`geometry_msgs/Twist`): Gimbal / manual override control values from virtual joystick.
* `/flight_command` (`std_msgs/String`): Executable commands (`START`, `PAUSE`, `RTL`, `EMERGENCY_LAND`, `DISARM_MOTORS`).



### C. Business Logic & Math Utilities (`src/utils/geo.js`)

Refactor the legacy raw JS logic into clean, tested React utility modules:

* `geoArea(vertices)`: Calculate geodesic polygon surface area in hectares ($ha$).
* `validBoundary(vertices)`: Validate polygon self-intersection and minimum 3 vertices.
* `generateLawnmower(polygon, swath, margin)`: Calculate parallel sweeping flight lines across the inset polygon.
* `inside(point, polygon)`: Point-in-polygon geofence containment verification.
* `updateFumigation()`: Calculate Variable Rate Application (VRA) flow rate based on speed, swath width, and target dosage.

### D. FPV HUD & Picture-in-Picture (PIP)

1. FPV primary view with animated HUD overlays (horizon line, pitch ladder, dynamic crosshair, REC indicator, HUD telemetry chips).
2. PIP Swap capability: Instantly toggle primary view between FPV camera feed (or RTSP stream placeholder) and Google Maps view.
